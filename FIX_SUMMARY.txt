📋 PROBLEM
──────────────────────────────────────────────────────────────────────────────
Error: Execution failed for task ':compileKotlin'
  > Inconsistent JVM-target compatibility detected for tasks 'compileJava' (21) 
    and 'compileKotlin' (17).

This prevented the backend from running in IntelliJ IDEA.

✅ ROOT CAUSES IDENTIFIED & FIXED
──────────────────────────────────────────────────────────────────────────────

1. Mismatched JVM Targets (PRIMARY ISSUE)
   Problem: Java compiler set to target 21, Kotlin compiler defaulting to 17
   Fix:     Added explicit Kotlin jvmTarget = '21' configuration

2. Incomplete Java Version Configuration
   Problem: sourceCompatibility was a string '21', not a proper JavaVersion
   Fix:     Changed to JavaVersion.VERSION_21 with matching targetCompatibility

3. Java Version System Incompatibility
   Problem: System default was Java 25, but Gradle 8.13 only supports up to 21
   Fix:     Configured to use Java 21 (available at /home/codespace/java/21.0.10-ms)

🔧 FILES MODIFIED
──────────────────────────────────────────────────────────────────────────────

1. backend/build.gradle
   ├─ Changed: sourceCompatibility = '21'  →  sourceCompatibility = JavaVersion.VERSION_21
   ├─ Added:   targetCompatibility = JavaVersion.VERSION_21
   └─ Added:   tasks.withType(KotlinCompile) { kotlinOptions { jvmTarget = '21' } }

2. backend/gradle/wrapper/gradle-wrapper.properties
   └─ Confirmed: gradle-8.13-bin.zip (compatible with Java 21)
